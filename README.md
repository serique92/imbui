# Imbui

Calculadora de custo por hora dos imbuimentos do Tibia.

- Preços de market por mundo via [TibiaMarket](https://www.tibiamarket.top/) (api.tibiamarket.top).
- Dados de personagem via [TibiaData](https://tibiadata.com/).
- Receitas e taxas conforme a [TibiaWiki](https://tibia.fandom.com/wiki/Imbuing).
- Página estática, sem build: abra `index.html` ou use o GitHub Pages.
